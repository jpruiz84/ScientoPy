# ScientoPy v3.2.0 — Release Notes

## Highlights

ScientoPy 3.2.0 adds the analyses that users had to do in other tools: an interactive network map (VOSviewer style), a thematic map, a world map of the documents per country, synonym merging, and a most cited documents table. The graphical interface was reorganized around them, with readable names, more options, and a Help menu.

---

## New Features

- **Network map (`scientoPyNetwork.py`):** co-occurrence network of the top items of a criterion: keyword co-occurrence, co-authorship, and country or institution collaboration. The analysis follows VOSviewer (association strength, clustering with a resolution parameter, VOS layout). The map is a single HTML file that opens in the web browser and works offline, with 3D and 2D views, overlays by year and citations, search, a guided tour, and image and video exports. The data is also saved as CSV, JSON, GEXF (Gephi), and VOSviewer files, including a table with the items of every cluster.
- **Thematic map (`scientoPyThematicMap.py`):** strategic diagram that places every cluster of topics by its Callon centrality (relevance) and density (development), as a motor, niche, basic, or emerging or declining theme. It uses the same clusters as the network map, so both figures agree.
- **World map (`scientoPy.py -c country -g world_map`):** shades every country by its number of documents, with an optional logarithmic color scale (`--yLog`). It works offline with country outlines from Natural Earth and needs no extra packages.
- **Synonyms (`--synonyms`):** counts the names of the same topic as one, in any criterion: keyword variants and abbreviations, author names, or institution names. Write the groups in the command, or load a VOSviewer thesaurus file. The same list works in the analysis, the network map, and the thematic map.
- **Most cited documents (`topCitedPapers.py`):** table with the most cited documents of the dataset, or of the documents found by the previous analysis, with the citations per year.

## Graphical Interface

- **Tabs in the order of the work:** Pre-processing, Analysis, Results, Documents, Network & Thematic Maps, and Export. "Extended Results" is now "Documents".
- **Readable names:** the lists show "Author keywords" or "Bars with trends" instead of `authorKeywords` or `bar_trends`. Hover an option to see its name in the scripts.
- **More options:** the Analysis tab now has the graph title and size, logarithmic scale, percentage per year, growth rate in the evolution graph, first author or country only, institutions of one country, and the word cloud mask. Each option is enabled only when it applies.
- **Dataset status:** the Pre-processing tab and the status bar show the documents and the publication years of the dataset. The year range of the analysis fits the dataset.
- **Custom topics and synonyms:** the boxes explain their format, and the synonyms are one list shared by the Analysis and Maps tabs.
- **Menus:** a File menu (select the dataset, run, open the results and graphs folders) and a Help menu (manuals, keyboard shortcuts, how to cite ScientoPy, and the version).
- **Results table:** opens the CSV file with one click, hides the years before the first document, and rounds long decimals.
- **Fewer dead ends:** the world map selects the countries criterion by itself, the start year cannot pass the end year, and "Use previous results" is available only after an analysis.

## Bug Fixes

- **Documents counted twice in grouped topics:** a document with several names of the same custom topic (for example `-t "IoT, Internet of Things"`, or a wildcard like `device*`) was counted once per name, which inflated the totals and the h-index. Each document now counts once per topic. Results of grouped or wildcard topics can be lower than in previous versions.
- **Progress dialog stuck after an error:** in the GUI, the progress dialog stayed open until Cancel when the analysis stopped with an error, for example a start year after the end year.
- **Cancel is not an error:** cancelling the preprocess no longer shows an error dialog.
- **Remembered settings:** the dataset folder typed by hand and the "Remove duplicated documents" choice are now saved.
- **Export destination:** it now follows the selected source, unless you wrote another one.

## Documentation

- Both user manuals were updated to this version, with the new tabs, options, and scripts.
