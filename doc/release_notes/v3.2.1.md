# ScientoPy v3.2.1 — Release Notes

## Highlights

ScientoPy 3.2.1 fixes a crash of the graphical interface in the 3.2.0 downloads: the application closed after an analysis with many documents. If you downloaded ScientoPy 3.2.0, replace it with this version. Everything that was new in 3.2.0 (network map, thematic map, world map, synonyms, and most cited documents) is described in the [v3.2.0 release notes](https://github.com/jpruiz84/ScientoPy/releases/tag/v3.2.0).

---

## Bug Fixes

- **Application closed after an analysis with many documents:** in the 3.2.0 downloads, the graphical interface closed without a message while it filled the Documents tab, usually on the second or third analysis of a large dataset (the terminal showed `Fatal Python error: none_dealloc`). It happened with any criterion and any graph, including the world map. The cause was a defect in version 6.12.0 of PySide6, the library that draws the interface. The downloads are now built with a PySide6 version that does not have it.
- **Running from the source code:** `requirements.txt` and the `gui` option of the package no longer install PySide6 6.12.0 on Python 3.11 and older, where the crash happens. If you installed the dependencies between October and this release with Python 3.11 or older, run `pip install -r requirements.txt` again.

## Infrastructure

- **Check of the interface library:** the tests now fill a table with the installed PySide6 and fail if it has this defect, so a release cannot be built with a version that closes the application.
